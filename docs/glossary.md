# Glossary

- **Anchor** — origin associated with an invoked interaction.
- **Compatible wallpaper** — dotted wallpaper accompanied by lattice metadata.
- **Dormant** — visible wallpaper nodes that are not active.
- **Embedded field** — lattice represented by dots already in the wallpaper.
- **Feathering** — continuous reduction of dot opacity toward a field boundary.
- **Node** — one dot in a field or wallpaper lattice.
- **Path** — visible connection constructed between nodes.
- **Signal** — animated activity traveling through nodes and paths.
- **Summoned field** — temporary dot matrix rendered over an ordinary wallpaper.
- **Surface** — shell UI such as an OSD, launcher, bar expansion, or notification.
