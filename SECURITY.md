# Security Policy

Dot Shell is pre-release software and does not yet provide a stable supported
version. Security reports are still welcome.

Please do not open public issues for vulnerabilities that could expose user
data, execute unintended commands, bypass the lock surface, or compromise IPC.
Use GitHub's private vulnerability reporting for this repository when enabled.

Include the affected revision, reproduction steps, impact, and any known
mitigation. Never include real secrets, tokens, or private user data.
